# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

A one-page marketing site for "Horizon Wealth Planning". The whole site is a single `index.html`, with CSS in one `<style>` tag and JS in one `<script>` tag. This is a hard constraint from the brief: use only vanilla HTML, CSS and JS, with no frameworks, build tools, package.json or extra files. Keep new code inside `index.html`.

## Commands

There is no build, lint or test tooling.

- Open in a browser: `start index.html` (PowerShell) or `Start-Process index.html`
- Syntax-check the JS: `sed -n '/<script>/,/<\/script>/p' index.html | sed '1d;$d' > "$TEMP/hw.js" && node --check "$TEMP/hw.js"`

The page needs internet access for Google Fonts (Playfair Display for headings, Inter for body), the Unsplash hero image and the `i.pravatar.cc` avatars.

## Architecture

The file follows the same order in all three layers, and each major block is marked with a `/* ===== N. NAME ===== */` banner comment (`<!-- ===== -->` in the HTML). Keep that convention when adding sections.

**CSS**
- The design tokens are custom properties on `:root`: `--navy #0B2545`, `--gold #C9A227`, `--bg #F7F9FC`, the spacing scale `--space-1…8`, and `--nav-h`. Use the tokens and don't hardcode values.
- Styles are mobile-first. The base styles are for mobile, the only breakpoints are `min-width: 768px` and `min-width: 1024px`, and they're grouped together near the end of the `<style>` tag, not scattered through it.
- A `prefers-reduced-motion` block turns off transitions and animations. The JS also checks `reduceMotion` and skips the counters and autoplay when it's set.
- The hero uses a negative `margin-top: -var(--nav-h)` so it sits under the sticky header. `scroll-padding-top` offsets the anchor jumps.

**JS**
Everything runs in one IIFE, split into sections: nav, scroll handler, fade-in, counters, carousel, enquiry form, newsletter and footer year.
- **Fade-in:** add the `.fade-in` class to any element (plus `.delay-1/2/3` if needed). One shared IntersectionObserver adds `.visible` to it.
- **Counters:** `.stat-number[data-target][data-prefix][data-suffix]`. Each has a sibling `.sr-only` span holding the final value for screen readers, and the animated span is `aria-hidden`.
- **Carousel:**
  - The number of cards shown is controlled by the CSS variable `--per-view` on `.carousel`, which is 1 by default and 3 at 1024px and up. The JS `getPerView()` must match the same breakpoint.
  - The track moves by `index * 100 / perView %`.
  - The dots are generated by JS (`maxIndex() + 1` of them) and rebuilt on resize.
  - Off-screen slides get `aria-hidden` and `inert`.
  - To add a testimonial, copy an `<li class="carousel-slide">` and update every slide's `aria-label="n of N"`.
- **Enquiry form:**
  - Validation is driven by the `validators` map, where each field name maps to a function that returns an error string (`""` means valid).
  - Each field needs a `.field` wrapper and a `<small id="{name}-error">`. `setFieldState` toggles the `.invalid` class and `aria-invalid`.
  - The radio group (`contactMethod`) is special-cased by id in `getFieldWrapper`.
  - There is no backend. A valid submit logs the data as JSON to the console after a 1.5s simulated delay and replaces the form with a success panel. The user's name is inserted with `textContent`.
- **Shared email regex:** `EMAIL_RE` is used by both the enquiry form and the newsletter form.
